## Ідея знака

Три мідні фрагменти утворюють асиметричний перерваний план. Одна бурштинова
траса входить зліва, змінює напрям усередині поля й завершується світлим
контрольним вузлом. Вузол фізично відокремлений від нижнього правого фрагмента
плану: у canonical-геометрії між намальованими формами залишається щонайменше
3 canonical units негативного простору. Відсутній четвертий кут створює
впізнаваний «вхід» і спрощує силует у малих розмірах. Знак пов'язує трасування
електромонтажу з керуванням розумним будинком без буквального будинку,
блискавки, вилки, лампи або декоративного монограма.

## Кольори

Активи використовують чинні токени інтерфейсу: мідь `#af5d38`, глибока мідь
`#59372a`, бурштин `#f6a45f`, світлий бурштин `#ffd0a1`, темне тло `#100d0c`,
світлий текст `#f7f2ed` та чорнило `#0b0908`. SVG-файли не містять градієнтів,
фільтрів або вбудованих растрових зображень.

## Застосування

- На темному тлі використовуйте `logo-dark.svg`; на світлому — `logo-light.svg`.
- Не додавайте слоган у lockup і не змінюйте пропорції, товщину фрагментів,
  траси або розміщення контрольного вузла.
- `mark.svg` є canonical-знаком для 24 CSS px і більше; у компактній навігації
  він також лишається впізнаваним на 16 px, але без гарантії всіх внутрішніх
  проміжків. `favicon.svg` — окрема micro-геометрія для favicon: вона зберігає
  три фрагменти, одну трасу і вузол, проте має товстіші штрихи, коротший маршрут
  та щільнішу посадку в плитку. У PWA використовуйте синхронні растрові
  `icon-192.png` і `icon-512.png`, згенеровані з цієї micro-версії.
- За 16 CSS px nominal stroke micro-версії дорівнює приблизно 2.33 CSS px;
  перевіряйте контраст на цільовому браузері та не масштабуйте canonical SVG
  нижче 16 CSS px.
- Охоронне поле навколо самостійного знака дорівнює щонайменше 1/6 його
  ширини. У горизонтальному lockup відступ до wordmark дорівнює приблизно
  0.55 висоти знака.
- Одноколірна версія призначена для обмежених технологією носіїв. За потреби
  її колір можна замінити під час друку або через безпечну інлайн-адаптацію.

## Wordmark та доступність

Словесна частина — title-case `Smart Electrics`, Manrope weight 650 із
ущільненим трекінгом. Живий сайт використовує локальні ліцензовані Manrope
webfonts. Редаговані SVG lockup реєструють локальний alias `ManropeBrand` і
задають стек `ManropeBrand, Avenir Next, Avenir, Helvetica Neue, Arial,
sans-serif` без зовнішнього мережевого завантаження. Для поліграфії, де
потрібна повністю незалежна геометрія, слід окремо створити й перевірити
path-експорт Manrope.

PNG-файли є зафіксованими web-версіями для випадків, де середовище не гарантує
однаковий системний шрифт. Після зміни SVG їх потрібно перегенерувати й
візуально перевірити на clipping та достатній clearspace.

Кожний SVG має власні `title` і `desc`. Коли знак дублює поруч видимий напис,
у розмітці сайту він позначається `aria-hidden="true"`, щоб назву не читали
двічі. Коли SVG використовується окремо як змістовний елемент, не прибирайте
його вбудовані accessibility-метадані.

## Оригінальність

Унікальна риса напряму — топологія «три фрагменти плану + один вхід + одна
маршрутизована траса + один вузол». Вона працює в монохромі й не покладається
на приховані літери. Архітектурні контури та circuit-мотиви самі по собі
поширені; ці файли не є підтвердженням правової чистоти. Перед реєстрацією або
великим тиражем потрібен професійний пошук торговельних марок та подібних
знаків на цільових ринках.
