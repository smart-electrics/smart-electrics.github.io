# Вибір напряму логотипа

Три незалежні напрями були створені як throwaway-прототипи й оцінені до
перенесення будь-якого production artwork у репозиторій.

| Напрям | Сильна сторона | Ризик | Рішення |
| --- | --- | --- | --- |
| A — Courtyard Circuit | Найчіткіше поєднує архітектурний план, електричну трасу й один керований вузол. | Загальна circuit-лексика поширена. | **Обрано й уточнено.** Вузол перенесено всередину контуру. |
| B — Routed Node | Виразний безперервний маршрут і добра динаміка. | Як окремий icon надто близький до загальної network/route символіки. | Не переносити prototype code у product. |
| C — Modular Signal Plan | Сильний модульний ритм і добра масштабованість. | Може читатися як maze, QR-фрагмент або абстрактна літера. | Не переносити prototype code у product. |

Напрям A виграв за відповідністю повному циклу робіт: контур нагадує
спроєктовану інфраструктуру, а внутрішня траса — контрольовану автоматизацію.
Фінальна геометрія та правила застосування наведені в `logo-guide.md`.

Візуальний артефакт порівняння: `output/playwright/logo-concepts.png`.
