# Triage labels

Skills Matt Pocock використовують п'ять канонічних ролей. Назви labels у GitHub мають точно відповідати цій таблиці.

| Роль skill | Label у GitHub | Значення |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Запит потребує оцінки відповідальним. |
| `needs-info` | `needs-info` | Бракує конкретної інформації від автора. |
| `ready-for-agent` | `ready-for-agent` | Запит достатньо визначений для виконання агентом. |
| `ready-for-human` | `ready-for-human` | Запит потребує рішення або виконання людиною. |
| `wontfix` | `wontfix` | Запит не буде виконано. |

Під час triage Issue має рівно один стан із цієї таблиці. Категорії `bug` або `enhancement` можна застосовувати додатково, коли вони існують у репозиторії.
