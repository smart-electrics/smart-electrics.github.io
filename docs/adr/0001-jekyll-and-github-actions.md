# Jekyll build deployed through GitHub Actions

Сайт буде статичним Jekyll-проєктом, а GitHub Actions збиратиме й публікуватиме його на GitHub Pages. Це зберігає джерело, збірку й хостинг в одному GitHub-репозиторії та відповідає обраному способу хостингу; перехід на інший генератор або платформу потребуватиме зміни build/deploy-контуру.

## Considered options

- Вбудована збірка Pages.
- Інший статичний генератор або зовнішній хостинг.
