# Project-local multi-agent workflow

Цей репозиторій фіксує Sol/xhigh як оркестратора, Terra для змістовної роботи та Luna для механічної верифікації в `.codex/`. Політика є локальною для проєкту, щоб її не змінювали глобальні особисті налаштування; незалежний read-only review є обов'язковою контрольною точкою перед PR.

## Considered options

- Покладатися лише на глобальні налаштування Codex.
- Один агент для планування, реалізації та схвалення.
