# Security policy

## Reporting a vulnerability

Не створюйте публічний Issue для потенційної вразливості, витоку секрету чи персональних даних. Використайте приватний канал, доступний власнику репозиторію (GitHub Security Advisories, якщо увімкнено), або зверніться до власника через підтверджений приватний контакт.

У повідомленні надайте мінімальний відтворюваний опис, потенційний вплив, уражений URL/файл або revision і безпечні кроки перевірки. Не додавайте токени, паролі, повні персональні дані чи активні exploit payloads.

## Scope

Цей репозиторій — статичний сайт. Повідомляйте про проблеми з залежностями, GitHub Actions, витіканням даних у репозиторій, конфігурацією Pages, небезпечними сторонніми скриптами та UI, який може вводити користувача в оману щодо безпеки або обробки даних.

Після підтвердження власник визначає виправлення та момент публічного розкриття. Не заявляйте про підтримку, строки реакції чи винагороду, якщо це не підтверджено окремо.
